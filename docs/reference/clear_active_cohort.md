# Clear the active patient subgroup filter

Clear the active patient subgroup filter

## Usage

``` r
clear_active_cohort(src_name = NULL)
```

## Arguments

- src_name:

  Source name to clear. NULL clears all sources.

## Value

`NULL`, invisibly.

## Examples

``` r
clear_active_cohort()
#> Active cohort filters cleared for all sources.
```
