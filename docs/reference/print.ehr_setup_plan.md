# Print an `rendehR` setup assistant plan

Displays the chosen sources, mode, database/directory targets, cohort
and analysis-level choices, the generated setup script, and the
recommended next steps.

## Usage

``` r
# S3 method for class 'ehr_setup_plan'
print(x, ...)
```

## Arguments

- x:

  An `ehr_setup_plan` object, as returned by
  [`ehr_setup_assistant()`](https://ate-driven-lab.github.io/rendehR/reference/ehr_setup_assistant.md).

- ...:

  Ignored.

## Value

Invisibly, `x`.
